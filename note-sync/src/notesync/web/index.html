Periodic notes

今天想记录什么？

选择一种周期，NoteSync 会生成结构清晰的 Markdown 模板，并立即用默认编辑器打开。

基准日期周度和月度笔记会根据这个日期归档
日

每日笔记

记录当天的想法、进展和待办。文件按年月自动归档。

周

周度笔记

使用 ISO 周编号，并预先生成周一到周日七个日期标题。

月

月度笔记

根据月份实际天数，为每天生成一个 Markdown 二级标题。

月度示例：周期笔记/月度/2026/2026-11.md
GitHub sync

同步设置

连接私有 GitHub 仓库后，新增和修改的文件会自动提交、合并并推送。

这里可以直接填写现有的 Obsidian Vault 路径
推荐使用已配置 SSH Key 的私有仓库
后台 Git 不会弹出密码输入框。请提前配置 GitHub SSH Key 或系统凭据管理器。NoteSync 发现同文件冲突时会保存双方版本，不会静默覆盖。
